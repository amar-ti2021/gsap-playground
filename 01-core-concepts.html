GSAP Core Concepts

Using gsap.to(). This animates the element from its original state TO the values we define (move right, scale up, rotate).

Using gsap.from(). The element starts FROM the values you define (invisible, 100px down) and animates to its original CSS state.

Using gsap.fromTo(). This gives us full control, defining both the FROM state (left, invisible, small) and the TO state (right, visible, bigger).
